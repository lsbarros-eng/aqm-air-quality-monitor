# Roadmap

## v0.1.x — Prototype stabilization

- Longer stability tests;
- improve wiring conventions and mechanical support;
- document supply-voltage measurements;
- compare SCD41 and BME280 temperature/humidity behavior;
- refine web labels and alert descriptions.

## v0.2.0 — Data logging

- synchronize the RTC;
- add microSD storage;
- create timestamped CSV files;
- log CO₂, both temperature channels, both humidity channels and pressure;
- define file rotation and safe-shutdown behavior.

## v0.3.0 — Portable hardware

- battery or regulated portable power;
- enclosure with controlled ventilation;
- sensor thermal isolation;
- robust connectors and strain relief.

## Future studies

- PM1.0/PM2.5/PM10 sensor integration through UART;
- larger SPI graphical display;
- dashboard modularization;
- Wi-Fi-independent measurement campaigns;
- calibration and comparison against reference instruments.
